# PE - Reportes PDF en el navegador en los ajustes de Perú (AL)

Documentación funcional: [Reportes PDF en el navegador](../../mkdocs/content/applications/general/report_preview.md)

Módulo puente `al_l10n_pe_report_preview` para Odoo 19 (`auto_install`):
con `al_account_base` y `al_report_preview` instalados, agrega a
**Ajustes ▸ Perú** el bloque **Reportes PDF** con el mismo campo
`al_report_preview_scope` de Ajustes generales y el acceso **Elegir por
reporte**. No tiene modelos ni datos propios.
