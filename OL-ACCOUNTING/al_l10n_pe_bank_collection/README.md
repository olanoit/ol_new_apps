# Recaudación bancaria (AL)

Archivo de deudores para el banco, importación de la respuesta, pagos y conciliación automática.
Formatos de ancho fijo configurables; incluye el CREP del BCP (validación completa).

Plan y fuentes: [docs/cobranza/](../../docs/cobranza/INVESTIGACION_Y_MEJORAS_V3.md). El layout BCP
precargado debe compararse con la ficha técnica que el banco entrega al afiliar.
