Análisis de la IPN
1. Prerrequisitos: Restricciones del servidor del vendedor
Suivez les instructions du chapitre : Préparer son environnement.
La regla principal es permitir el rango de direcciones IP 194.50.38.0/24, puerto predeterminado 443 (HTTPS) en tu servidor.
2. Los datos transmitidos
Paramètre	Descripción	VALOR
kr-hash-key	Mot de passe de test ou de production selon le cas (2 ème clé du tableau des clés API REST ). Clé utilisée pour signer kr-answer.	password
kr-hash-algorithm	Algoritmo utilizado para calcular el hash.	Su valor es sha256_hmac.
kr-answer	Objeto que contiene el resultado del pago, codificado en JSON.	Ex : {"shopId":"89289758","orderCycle":"CLOSED","orderStatus":"PAID", (...)
kr-answer-type	Tipo de objeto JSON contenido en kr-answer .	Ex : V4/Payment
kr-hash	Hash del objeto JSON almacenado en kr-answer Te permite verificar la autenticidad de la respuesta.	Ex: c3c0323c748fdb7c2d24bd39ada99663526236828efa795193bebfdea022fe58
kr-src	Origen de la notificación.	EMBEDDED_FORM para el formulario incrustado
Advertencia
Los datos transmitidos pueden cambiar.
3. Verificar la autenticidad del IPN
Debe verificar la autenticidad de los datos recibidos.
Encriptarlo kr-answer recibido usando la función hash_hmac:
Algoritmo de cifrado: sha256
Clave secreta: la contraseña que empieza por testpassword o prodpassword ( 2ª clave de la tabla de claves de la API REST ).
Base de codificación: hexadecimal ( base 16 ).
Verifica la autenticidad del mensaje recibido:
si el kr-hash es igual al cifrado de kr-answer, entonces el mensaje es auténtico.

5. Reproducción del IPN
En cas d'échec, un mécanisme de rejeu automatique se configure lors du paramétrage de l'IPN : lien.
Si habilita la reproducción, la plataforma reenvía automáticamente el IPN En caso de fallo, cada 15 minutos, hasta 4 veces.
Si no desea esperar tanto tiempo, utilice el Servicio Web Order/Get para recuperar la lista de transacciones asociadas a una referencia de pedido ( ID del pedido).
Se recomienda:
Realizar solo una llamada por minuto.
Esperar la respuesta antes de realizar otra llamada.
