Análisis del resultado del pago con "regresar a la tienda"
Si ha establecido el parámetro kr-post-url-success , la información de pago se transmitirá a la URL definida.
Si l'acheteur paie avec un moyen de paiement différent de la carte (ou wallet), une fenêtre avec le ticket de paiement s'affiche. Pour masquer cette fenêtre, voir : lien.
I. Los datos transmitidos
Paramètre	Descripción	VALOR
kr-hash	Hash del objeto JSON almacenado en kr-answer. Así podrá confirmar la autenticidad de la respuesta.	Ejemplo: c3c0323c748fdb7c2d24bd39ada99663526236828efa795193bebfdea022fe58
kr-hash-algorithm	Algoritmo utilizado para calcular el hash.	Su valor es sha256_hmac
kr-answer-type	Tipo del objeto JSON almacenado en kr-answer.	Ejemplo: V4/Payment
kr-answer	Objeto que contiene el resultado del pago, codificado en JSON.	Ex : {"shopId":"89289758","orderCycle":"CLOSED","orderStatus":"PAID", (...)
kr-hash-key	Clave HMAC-SHA-256 ( 4ª clave de la tabla de claves de la API REST ). Clave utilizada para firmar kr-answer.	sha256_hmac (regresar a la tienda).
Advertencia
Los datos transmitidos pueden cambiar.
II. Verificar la autenticidad del proceso "volver a la tienda"
Debe verificar la autenticidad de los datos recibidos.
Cifrarlokr-answerrecibido utilizando la funciónhash_hmac
Algoritmo de cifrado : sha256.
Clave secreta: Clave HMAC-SHA-256 ( 4ª clave de la tabla de claves de la API REST ).
Base de codificación: hexadecimal (base 16).
Compruebe la autenticidad del mensaje recibido
si el kr-hash es igual a la encriptación del kr-answer el mensaje es auténtico.
Ejemplo de código del archivo de ejemplo: paid.php
PHP
Copy
// STEP 1 : check the signature with the SHA_KEY on the file config.php
if (!checkHash($_POST, SHA_KEY)) {
    echo 'Invalid signature. <br/>';
    die();
}
$answer = array();
$answer['kr-hash'] = $_POST['kr-hash'];
$answer['kr-hash-algorithm'] = $_POST['kr-hash-algorithm'];
$answer['kr-answer-type'] = $_POST['kr-answer-type'];
$answer['kr-answer'] = json_decode($_POST['kr-answer'], true);
function checkHash($data, $key)
{
    $supported_sign_algos = array('sha256_hmac');
    if (!in_array($data['kr-hash-algorithm'], $supported_sign_algos)) {
        return false;
    }
    $kr_answer = str_replace('\/', '/', $data['kr-answer']);
    $hash = hash_hmac('sha256', $kr_answer, $key);
    return ($hash == $data['kr-hash']);
}
?>
