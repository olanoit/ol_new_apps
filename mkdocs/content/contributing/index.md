# Aportando

La documentación de la suite sigue el modelo de la
[documentación de Odoo](https://www.odoo.com/documentation/19.0/es_419/): un sitio
por versión de Odoo, organizado por áreas de negocio y escrito para quien usa el
sistema. Esta sección explica cómo está organizada y cómo escribir una página.

| Para | Lea |
|---|---|
| Saber dónde va una página nueva | [Organización de la documentación](documentation/organization.md) |
| Escribir o revisar una página | [Pautas de contenido](documentation/content_guidelines.md) |
| Dar formato (avisos, menús, imágenes) | [Pautas de Markdown](documentation/markdown_guidelines.md) |
| Empezar una página desde cero | [Plantilla de página](documentation/page_template.md) |
| Ver el resultado y publicarlo | [Publicar la documentación](documentation/publishing.md) |
