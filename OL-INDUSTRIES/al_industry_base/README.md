# Industrias: base común (AL)

Lo que comparten los paquetes de industria que facturan desde Odoo: el registro de industrias y la localización peruana de la suite con comprobantes electrónicos.

El modelo `al.industry` está en [`al_industry_core`](../al_industry_core/), que no instala comprobantes electrónicos.

Documentación funcional: [Industrias](../../mkdocs/content/industries/index.md)

Paquete de industria (`OL-INDUSTRIES/`): ver el README de la carpeta.
