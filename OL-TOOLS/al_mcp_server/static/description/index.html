Guía de administración

¿Cómo realizas el mantenimiento en Odoo?

El Servidor MCP incluye controles de administración integrados — gestiona tokens, audita sesiones, vacía la caché, define políticas de retención y prueba la conectividad con Redis — todo desde la Configuración de Odoo.

Capturas de pantalla

Recorrido visual

OAuth 2.0 Autorizar acceso

Flujo de código de autorización OAuth 2.0 conforme al estándar, con PKCE S256. Los usuarios autorizan a los clientes MCP mediante una pantalla de inicio de sesión con marca propia — las credenciales nunca salen de Odoo.

Tokens de acceso personal

Cada usuario puede generar sus propios tokens de acceso personal con alcance para herramientas de línea de comandos, pipelines de CI e integraciones sin interfaz. Cifrados con hash SHA-256 en reposo, mostrados solo una vez.

Gobernanza de tokens

Configura el alcance por token (solo lectura, lectura-escritura, administrador), lista de modelos permitidos, lista de campos permitidos, lista de IP permitidas/denegadas y captura de carga útil para auditoría — acceso de mínimo privilegio por defecto.

Rastro de auditoría de sesiones

Cada sesión MCP se registra con el tipo de transporte, la dirección IP, el número de llamadas a herramientas, la duración y (opcionalmente) las cargas útiles completas de solicitud/respuesta con ocultación de PII.

Cola de trabajos asíncronos

Delega el trabajo pesado — actualizaciones masivas, exportaciones masivas, automatizaciones de varios pasos — a una cola en segundo plano. Consulta el progreso, inspecciona las cargas útiles, reintenta los fallos y devuelve los resultados al cliente de IA sin alcanzar los límites de tiempo de espera HTTP.

Páginas de portal generadas por IA

Pídele a Claude que "cree un tablero de envíos en /mcp-page/shipping" y obtén una página pública y adaptable a móviles, renderizada en el servidor a partir de datos de Odoo en vivo — tarjetas KPI, visualizaciones de ECharts y tablas interactivas, sin necesidad de trabajo de front-end.

Generador del prompt al módulo

Describe el módulo que necesitas en lenguaje natural. Claude produce una especificación validada, el generador construye un módulo de Odoo completo (modelos, seguridad, vistas, menús) y puedes instalarlo directamente o descargar el ZIP para revisarlo.

Un solo panel de configuración para todo lo de MCP

Gestiona políticas de retención, límites de tasa, caché de Redis, TTL de la caché de esquema y el indicador de función del generador de módulos — todo desde una única pantalla dentro de la Configuración de Odoo. No se requiere ninguna interfaz de administración externa.

Funciones

Lo que obtienes

Conectividad y autenticación

🔐 OAuth 2.0 + PKCE

Flujo de código de autorización conforme al estándar, con PKCE S256, registro dinámico de clientes (RFC 7591), rotación de tokens de refresco y autodescubrimiento mediante los endpoints /.well-known.

🔑 Tokens de acceso personal

Gestión de tokens en autoservicio. Cada usuario genera sus PAT para integraciones sin interfaz. Se guardan con hash SHA-256 y se muestran una sola vez al crearlos.

⚡ Doble transporte

Transporte Streamable HTTP (especificación MCP 2025-03-26) más SSE heredado — funciona con Claude Desktop, ChatGPT, Cursor, Gemini, n8n, LangChain y cualquier cliente compatible con MCP.

Gobernanza y auditoría

🛡️ Alcance por token

Solo lectura, lectura+escritura o administrador. Limita el radio de impacto de cada token. Combínalo con la lista de modelos y de campos permitidos para un acceso preciso de mínimo privilegio.

🌐 Listas de IP permitidas y denegadas

Restricciones de IP por token basadas en CIDR. Limita los tokens a la red de tu oficina, al rango de tu VPN o a un servidor de automatización concreto.

🔎 Rastro de auditoría + ocultación de datos

Cada llamada a una herramienta se registra con su duración, número de registros y resultado. Captura opcional de la carga útil con ocultación automática de datos personales (contraseñas, tokens, números de identidad, tarjetas de crédito).

Capacidades avanzadas

📊 Herramientas de reportes BI

Siete herramientas de análisis en una sola llamada: tablas dinámicas, series de tiempo con relleno de huecos, ranking top-N, retención por cohortes, conversión de embudo y exportaciones CSV y XLSX.

🌍 Páginas de portal

Tableros públicos compartibles con tarjetas KPI, visualizaciones ECharts y tablas. Renderizados en el servidor, siempre en vivo, adaptables a móvil e incrustables mediante URL firmada.

⚙️ Cola de trabajos asíncronos

Envía actualizaciones masivas, exportaciones de más de 100 000 registros o llamadas a métodos pesados y consulta su estado. Un cron en segundo plano procesa los trabajos respetando el alcance y las restricciones del token.

Infraestructura

Despliegue y rendimiento

Diseñado desde cero para producción, con escalabilidad horizontal y observabilidad.

🚀 Escalabilidad horizontal
  • Funciona con 1 worker, 10 workers o más de 100 workers
  • Límite de tasa distribuido respaldado por Redis (sin coordinación adicional)
  • Caché compartida de esquemas de modelos entre todos los workers
  • No requiere afinidad de sesión ni sesiones persistentes
  • Respaldo automático si Redis no está disponible
⚡ Pruebas de rendimiento
  • Solicitudes en caché: ~2 ms (96 % más rápidas)
  • Solicitudes sin caché: ~50-100 ms (estándar)
  • Rendimiento: 4 veces mayor con caché
  • Tasa de aciertos de caché: 80-90 % habitual
  • Percentiles de latencia: p50: 3 ms, p95: 25 ms, p99: 80 ms

Modos de transporte

Streamable HTTP
POST /mcp — especificación MCP 2025-03-26. Sin estado, sin sesiones persistentes, escala horizontalmente.
Server-Sent Events
GET /mcp/sse + POST /mcp/messages — transporte MCP heredado para clientes antiguos.
Portal HTTP
GET /mcp-page/<slug> — tableros públicos respaldados por datos de Odoo en vivo.

Guías de integración

Cómo conectarse

Conecta tu cliente de IA favorito a los datos de Odoo en vivo en minutos. Sin escribir código.

Paso a paso

Conectar con Claude Web

Usa Claude.ai con MCP para consultar datos de Odoo, crear registros, ejecutar reportes y construir tableros — directamente desde tu navegador.

  1. Instala Servidor MCP para Odoo desde el menú Aplicaciones.
  2. Ve a Servidor MCP → Configuración y copia la URL de tu endpoint MCP.
  3. En Claude.ai, abre la configuración de tu proyecto y agrega una nueva integración MCP.
  4. Pega el endpoint MCP de tu Odoo y autoriza mediante OAuth 2.0.
  5. Empieza a conversar — pídele a Claude que busque registros, cree facturas o construya un tablero.

Paso a paso

Conectar con Grok

Grok admite conexiones MCP para usar herramientas. Vincúlalo a tu instancia de Odoo y consulta los datos de tu negocio en lenguaje natural desde la interfaz de Grok.

  1. Genera un token de acceso personal desde tu perfil de usuario de Odoo.
  2. En la configuración de herramientas de Grok, agrega un nuevo servidor MCP con la URL del endpoint de tu Odoo.
  3. Ingresa tu token Bearer para la autenticación.
  4. Grok descubrirá automáticamente todas las herramientas de Odoo disponibles mediante tools/list.
  5. Pídele a Grok que traiga datos del CRM, ejecute análisis o genere un reporte.

Paso a paso

Conectar con ChatGPT

ChatGPT admite servidores MCP mediante su sistema de conectores. Apúntalo al endpoint MCP de tu Odoo y dale acceso a los datos de tu ERP en vivo.

  1. Ve a Servidor MCP → Gestión → Tokens y crea un token con el alcance necesario.
  2. En la configuración de ChatGPT, entra en Connectors (conectores) y agrega una nueva conexión MCP.
  3. Ingresa la URL MCP de tu Odoo y pega tu token Bearer.
  4. ChatGPT descubrirá automáticamente todas las herramientas desde el endpoint tools/list.
  5. Inicia un chat: «¿Cuáles son mis 5 mejores clientes por ingresos este mes?»

Preguntas frecuentes

¿Tienes preguntas?

¿Qué clientes de IA pueden conectarse a este servidor MCP?
Cualquier cliente que implemente el Model Context Protocol — entre ellos Claude Desktop, Claude Code, Cursor, ChatGPT, Gemini, n8n, LangChain, crewAI y aplicaciones propias compatibles con MCP. Se admiten tanto el transporte Streamable HTTP (especificación MCP 2025-03-26) como el SSE heredado.
¿Cómo se gestiona la autenticación? ¿Se guardan credenciales?
La autenticación se delega por completo en res.users de Odoo — no hay una base de usuarios aparte. El flujo de código de autorización OAuth 2.0 con PKCE S256 emite tokens Bearer de 30 días con tokens de refresco de 90 días. Los tokens se guardan con hash SHA-256; solo se almacena el hash. Este módulo nunca guarda contraseñas.
¿Puedo limitar lo que un token puede leer o escribir?
Sí. Cada token tiene un alcance configurable (solo lectura, lectura+escritura, administrador), una lista opcional de modelos permitidos y denegados, una lista de campos permitidos (JSON por modelo) y listas de IP permitidas y denegadas con soporte CIDR. Todas las comprobaciones se aplican en el servidor antes de cualquier operación del ORM. Además, siguen vigentes las ACL y las reglas de registro de Odoo — el token no puede saltárselas.
¿Qué herramientas recibe el cliente de IA de serie?
Más de 30 herramientas MCP en varias categorías: CRUD (search, read, create, update, delete, call_method); flujo de trabajo (message_post, default_get, onchange, get_views, print_report, create_attachment); analítica (count, name_search, read_group); reportes BI (pivot, time_series, top_n, cohort, funnel, export_csv, export_xlsx); operaciones (submit_job, job_status, job_list, job_cancel, create_portal_page, list_portal_pages, update_portal_page); generación de módulos (validate_module_spec, generate_module, list_generated_modules, install_generated_module).
¿Qué son las páginas de portal y cómo funcionan?
Las páginas de portal son tableros públicos compartibles respaldados por datos de Odoo en vivo. Un agente de IA puede crear un tablero con odoo_create_portal_page y una especificación JSON que describe tarjetas KPI, visualizaciones ECharts y tablas. El resultado es una URL limpia como /mcp-page/sales-dashboard, con tokens firmados opcionales para incrustarla en un iframe. Las páginas se renderizan en el servidor, se adaptan a móvil y se ejecutan como el usuario que las creó, con sus permisos.
¿Para qué sirve la cola de trabajos asíncronos?
Las operaciones pesadas — actualizaciones masivas de miles de registros, exportaciones CSV/XLSX de grandes volúmenes, llamadas a métodos por lotes — superan los tiempos de espera HTTP normales. La cola asíncrona permite a la IA enviar un trabajo, recibir un job_id al instante y consultar su estado hasta que termine. Un cron en segundo plano procesa los trabajos respetando el alcance y las restricciones originales del token. Las exportaciones generan adjuntos descargables.
¿Cómo funciona el generador de módulos? ¿Es seguro?
La IA envía una especificación JSON que describe un módulo — modelos, campos, vistas, seguridad. El generador valida la especificación (nombres en snake_case, palabras reservadas, lista de tipos de campo permitidos, análisis AST de cada archivo .py generado) y produce un archivo ZIP instalable. La instalación está desactivada por defecto y requiere alcance de administrador y una ruta de extracción configurada (se niega a escribir en las carpetas community/ o enterprise/). Si la instalación falla, una reversión atómica elimina los archivos extraídos.
¿Qué hay del límite de tasa y del rendimiento a gran escala?
Por defecto, un limitador de ventana deslizante acota las solicitudes por token. En despliegues de Odoo con varios workers o instancias, configura una URL de Redis en los ajustes del servidor MCP y el limitador pasa a una ventana deslizante sobre conjuntos ordenados de Redis, con latencia inferior al milisegundo. Una caché de esquema (LRU, TTL configurable) reduce mucho la latencia de fields_get, get_models y get_views, con invalidación automática cuando cambian ir.model o ir.model.fields.
¿Está disponible para Odoo Community y Enterprise?
Sí. El módulo está disponible para las ediciones Community y Enterprise, así como para Odoo.sh y despliegues on-premise. No depende de ningún módulo exclusivo de Enterprise.
¿La compra incluye las actualizaciones a versiones futuras?
Cada compra cubre la versión de Odoo adquirida. Las actualizaciones a versiones mayores posteriores están disponibles a un precio reducido. Las correcciones de errores y las actualizaciones menores dentro de la misma versión son gratuitas.
